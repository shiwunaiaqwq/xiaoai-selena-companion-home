# 小爱与赛琳娜 · 她们的家（改编版）

本项目基于 **[Cabin World / 小屋世界](https://github.com/BabyBus2022/cabin-world)** 改编。原项目署名：**Cabin World by VADS**。这不是原作者发布的官方版本。

在原项目基础上加入小爱（爱弥斯）与赛琳娜的人物素材、家具交互、AstrBot 生活安排、共同生活记录、礼物与好感度、小屋日记和姐妹对话。原项目与改编部分的许可边界见 [署名与许可](ATTRIBUTION.md)。

这是从个人运行环境整理的源码分享版。没有附带账户、聊天、私人记忆、密钥、Cookie、登录密码或已经发送的日记。安装后从空白生活记录开始；它不是一键恢复我的机器人账号。

## 内容

- `cards/`：两位人物卡、背景摘要、对白示例；赛琳娜情话独立存放。原作引用与新写示例的来源字段保留。
- `astrbot_plugin_companion_home/`：AstrBot 小屋生活插件与网页面板，内置可移植人物卡。
- `character-edition/game/`：改编后 Godot 游戏源码和素材。
- `astrbot-link/`：读取同一小屋状态的本机桥接程序，不另造一套 AI 日程。
- `examples/`：不含实际账号的配置示例。
- `licenses/upstream/`：原项目许可、许可说明与来源文件。

## 生活方式

两位共享世界，分别保存自己的活动与经历。下一项日常通常在 20～60 分钟后安排，三餐、洗漱、睡觉优先。赛琳娜较早起床，小爱晚一些；各房间对应现有家具和动作。查看、跟随角色不会更改她们的真实安排。

主人可以改变活动和位置，普通群友不能操控。可选的姐妹群对话与视频分享每天共用 5 次额度，每段最多 10 句，可提前结束。小屋日记与 QQ 空间日记是两件事：本包不附带空间发布插件，也不会自动补发你的私人内容。

小爱的人格成长模块可以启用并回退；默认没有任何个人经历。B站浏览、QQ空间、具体 QQ 消息适配器和外部记忆插件是可选依赖，没有把它们的账号或全部源码塞入此包。未安装时，对应联动不可用。

## 安装概览

完整步骤见 [安装说明](docs/INSTALL.md)。需要 AstrBot、当前小屋兼容版本的 Godot 4.7、Node.js 22.13+，以及你自己的模型接口。QQ 功能还需要自己配置 OneBot 适配器。

1. 给两个 AstrBot 实例分别安装 `astrbot_plugin_companion_home`，设置不同的 `character`，但填写相同的 `shared_directory`。
2. 填自己的主人 QQ、会话来源和模型；在 AstrBot 人格管理中导入 `cards/` 的人物卡。插件内置副本用于小屋内部规划，不能替代主聊天人格的配置。
3. 两实例运行并生成小屋数据库之后，设置 `COMPANION_HOME_DB` 指向该数据库，启动 Node 桥接。
4. 用 Godot 导入 `character-edition/game/project.godot`，将桥接数据目录作为 `--data` 参数运行。

功能来源于正在使用的本地改编版本；公开包做了路径与账号参数化检查，尚未在另一台全新电脑完成端到端安装验证。请先使用测试账号和测试数据。
